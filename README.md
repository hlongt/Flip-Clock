# 翻页时钟 · Flip Clock

一只纸感的极简翻页时钟。单个 HTML 文件，零依赖、零网络请求，双击即可离线运行。

## 特性

- **真实翻页动画**：按 Solari 翻页牌的运动模型实现——上半叶以中缝为铰链向下倒伏，下半叶随即向下展开盖住旧值，带叶片投影与中缝高光，单次翻页 520ms。
- **纸感卡片**：卡片长期保持纸面质感（不接受"关闭卡面"），圆润的 Fredoka 字体，数字按墨迹上下留白做光学居中。
- **Earth Light**：开启后整套配色由当前时刻的太阳高度角驱动，从深夜、天文暮光、航海暮光、蓝调时刻、日轮交界、日出日落、黄金时刻，一路过渡到日间与正午。卡片与背景共用同一束天光，暗场景下自带轮廓光。
- **观察点**：日出日落、太阳方位、背景光晕落点都按选定的城市计算，而非按本机时区估算。
- **全屏与沉浸**：全屏后 3 秒无操作自动收起控件、隐藏光标。
- **记住偏好**：小时制、缩放、Earth Light 开关、所在城市都存在本地，下次打开自动恢复。

## 快速开始

1. 双击 `index.html`，用浏览器打开即可。
2. 右上角两个圆形按钮：左侧全屏、右侧设置。
3. 需要分享或备份时，只需这一个文件（字体已内嵌，不依赖任何外部资源）。

## 设置项

- **小时制**：24 小时 / 12 小时（12 小时制在秒牌右上角显示 AM / PM 角标）。
- **缩放**：60% – 150%，可拖动滑杆，也可直接键入数值，两者双向联动。
- **Earth Light**：按当前时间与观察点的太阳高度角实时换色。
- **位置**：深圳（默认）、北京、上海、广州、伦敦、巴黎、纽约、洛杉矶、迪拜。切换城市会同时改变日出日落时刻、太阳方位与光晕落点。

### Earth Light 面板里能看到什么

- **天光色带**：一整天的背景色变化，游标指着此刻。
- **阶段名称**：深夜 / 天文暮光 / 航海暮光 / 蓝调时刻 / 日轮交界 / 日出·日落 / 晨光·暮光时刻 / 上午·午后 / 正午。
- **日出日落**：按所选城市的当地钟表时间显示。

关闭 Earth Light 会平滑回到默认的日间纸感，且默认配色与开启时"日间"这一档逐色一致。

## 设计说明

- **翻页**：每个数字位一块 Canvas，静止时整卡一次绘制；翻页时对上下半区做 clip 与 `scale(1, ±cos)` 折叠，缓动为 easeInOutCubic。尊重系统的"减少动态效果"设置。
- **配色**：所有色彩都在 OKLab 空间插值与混合，避免蓝→橙直接混出脏灰；9 个光况关键帧覆盖太阳高度角 −90° 到 +32°，按高度角插值，过渡由 `requestAnimationFrame` 限帧驱动。
- **卡片与背景的关系**：每帧的卡片色都从同一束天光里"取"——色相贴背景光晕，彩度约为背景的一半，明度只比背景高一档；卡片顶部还叠了一层取自天光的环境反射，因此不会出现"彩色天 + 一块发光白板"的割裂感。
- **天文计算**：太阳赤纬 + 时角求高度角与方位角；日出日落用 −0.833° 的高度角反解，并计入均时差；跨时区城市用 IANA 时区名换算当地钟表时间（自动处理夏令时），实测与真实天文数据误差在 1–2 分钟内。
- **字体**：Fredoka SemiBold，用 fontTools 裁出 `0-9 / A / P / M` 子集（约 2KB），base64 内嵌进 HTML。

## 兼容性

- Chrome / Edge / Safari / Firefox 近两年版本。
- 使用 Canvas 2D、CSS 自定义属性、OKLab 色彩运算、`Intl.DateTimeFormat` 时区换算。
- 响应式：窄至 390px 的手机屏幕上无横向溢出。
